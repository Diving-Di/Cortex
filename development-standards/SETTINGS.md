# 设置页功能设定

> 功能编号：DL-310 ～ DL-313
> 页面路由：`/settings`
> 状态：功能已实现并通过自动化验证
> 关联文档：`SDD.md`

## 1. 目标

设置页只用于管理当前浏览器的界面主题。页面视觉延续现有应用布局：保留左侧导航，右侧内容区使用“外观”卡片展示主题选择控件。

AI 供应商、API 地址、模型、API Key 状态和连接测试均不在设置页展示。AI 配置由部署人员在后端运行环境中维护，不属于普通页面设置。

## 2. 主题设置

提供三种主题：

- `跟随系统`
- `浅色`
- `深色`

默认值为“跟随系统”。选择后立即生效，无需保存按钮，并持久化到当前浏览器的 `localStorage`，键名为 `diary-listener.theme`。

主题必须覆盖：

- 页面背景、侧边栏、卡片、文本、边框和悬浮/选中状态。
- Ant Design 组件主题。
- Markdown 编辑器、预览区和代码块。
- 弹窗、消息提示、下拉菜单和加载/空状态。
- 浏览器 `theme-color` 元数据。

“跟随系统”通过 `prefers-color-scheme` 判断，并监听系统主题变化。主题切换不得刷新页面，不得造成明显闪白；初始化时应在首屏渲染前应用已保存的主题。

主题偏好属于本机 UI 状态，不上传服务端，不进入备份，也不在不同浏览器之间同步。

## 3. AI 配置边界

使用云端 AI 时，API Key 必须发送给 AI 供应商用于鉴权，因此无法做到“密钥完全不离开本机”。Diary Listener 采用后端环境配置：

```dotenv
AI_API_KEY=<供应商 API Key>
AI_BASE_URL=https://api.example.com/v1
AI_MODEL=<模型名称>
```

- 设置页不提供 AI 配置、状态展示、连接测试或 API Key 输入框。
- API Key 不进入前端状态、浏览器存储、URL、Cookie、HTML、Source Map 或前端构建产物。
- 后端仅从运行环境或本机、且被 Git 忽略的安全配置读取 Key。
- API Key 不得出现在 API 响应、异常堆栈、普通日志、审计详情或备份包中。
- `.env`、`backend/config.json` 和其他本地秘密文件必须被 Git 忽略。
- 未配置 AI 或 AI 服务不可用时，普通笔记、搜索、导出和备份功能仍须正常工作。

## 4. 交互与无障碍

- 页面加载主题不依赖网络。
- 用户退出登录后保留本浏览器主题偏好。
- 非法或损坏的本地主题值自动回退到“跟随系统”。
- 所有控件支持键盘操作、可见焦点和屏幕阅读器标签。
- 浅色和深色主题的正文至少满足 WCAG AA 对比度。

- 刷新页面后继续使用已保存的主题。
- 非法或损坏的 `localStorage` 值回退到“跟随系统”。
- 搜索前端源代码、Source Map、静态产物和浏览器存储，确认不存在 API Key。
