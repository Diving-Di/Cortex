# Cortex 实现与生产验收待办

> 状态：未完成、部分完成和待验证事项的唯一清单
> 更新日期：2026-07-27
> 当前发布结论：**不通过，禁止发布**

本文只记录尚未完成的工作和缺失的生产证据。已经落地的设计与代码基线见
[软件设计说明书](SDD.md)。

状态定义：

- **未实现**：仓库中没有对应能力，或现有实现无法完成声明行为。
- **部分实现**：主链路存在，但分层、安全、恢复或用户操作不完整。
- **待验证**：已有代码或配置，但缺少可复现的端到端、隔离、性能或生产环境证据。
- **非 MVP**：明确不在当前范围，不作为发布阻断。

## 1. 发布阻断项

### P0：取得并固定 pgvector 镜像

当前环境拉取 `pgvector/pgvector:0.8.1-pg16-bookworm` 超时。目标环境需要：

- 将可信镜像同步到可用 Registry。
- 在 Compose 中固定镜像 digest。
- 使用隔离空库执行迁移、RLS、低权限授权、注册和登录验收。

### P0：配置真实生成模型

知识问答和现有 AI 工作流需要有效 LiteLLM virtual key 及至少一个可用生成模型。
验收不得输出 Key，并需分别验证生成供应商、Ollama 和 reranker 不可用时的脱敏错误与降级。

### P0：完成知识库端到端和双租户验收

- 两个租户分别上传相同文件名、相同摘要和语义相似内容。
- 列表、详情、下载、删除、FTS、向量、rerank、Chat 和引用均不得跨租户。
- TXT、文本 PDF、DOCX 完成上传—解析—索引—检索—问答—删除。
- 删除后立即不再召回，旧 worker 不得重新激活文档。

### P1：完成检索质量和性能门槛

建立固定评测集并记录：

- Recall@8。
- MRR/nDCG。
- citation precision。
- 无答案准确率。
- P95 检索和端到端延迟。

## 3. 部分实现、仍需补全

### 3.1 文件解析

- 增加真实中文、英文和中英混合 TXT/PDF/DOCX 自动化样本。
- 覆盖损坏、加密、扫描、复杂多栏 PDF、重复页眉页脚、跨页段落和表格。
- 证明 PDF 页数、字符数、对象数量、解析时间和资源上限有效。
- 确认所有失败返回稳定错误码，日志不含正文、原路径或文件名。

### 3.2 父子切块

- 实现或验证 PDF 阅读顺序、跨页语义和重复页眉页脚处理。
- 表格按重复表头的行组切割。
- 命中父块边界时，按预算选择性加入相邻 parent。
- 增加文档树、结构边界、表格和部分批次故障测试。

### 3.3 模型客户端与缓存

- 经 LiteLLM 验证本地 `qwen3-embedding:0.6b` 单条、16 条批量、中文、英文和混合输入。
- 确认返回数量、顺序和 1024 维，覆盖超时、不可达、维度异常和部分批次失败。
- 实现同租户 `content_hash + embedding_model` 的安全复用，或明确不缓存。
- 证明不存在跨租户 embedding 内容缓存。
- 用固定评测集确认可选 BGE reranker 对 nDCG/MRR 的实际收益。

### 3.4 索引 worker

- 增加多 worker、多 backend、租约过期、幂等和故障重试测试。
- 覆盖删除、重传和索引并发，确保旧任务不能重新激活失效文档。
- 验证旧代次清理和模型升级回填不会混用向量空间。

### 3.5 删除恢复

- 为磁盘清理失败增加持久化可重试任务。
- 数据库步骤失败时恢复 tombstone 文件名。
- 保证 DELETE 幂等并增加并发删除测试。
- 历史 UI 将已删除引用显示为不可用，不允许下载或展示旧片段。
- 明确文件彻底删除和本地模型日志保留承诺。

### 3.6 检索与隔离

- 增加相邻 parent 扩展。
- 增加相同文本、相似文本、相同文件名和相同摘要的双租户隔离测试。
- 验证 collection/document 伪造、缺失 RLS 上下文和低权限角色行为。
- 记录 FTS 降级、reranker 降级、统一 token 预算和旧代次排除的端到端证据。

### 3.7 Docker 与可观测性

- 固定 PostgreSQL pgvector 镜像 digest。
- 固定 Ollama 模型 digest。
- reranker 生产启动时不得从公网动态下载模型，改用只读持久化模型卷。
- 增加 warm-up、队列长度、失败数、处理时长和检索延迟指标，不记录正文。
- 验证容器重建后数据库、附件和知识文件仍存在。
- 验证 `db`、`llm-gateway` 和 `backend` healthy。

## 4. 生产复验步骤

解除 P0 环境阻断后，在隔离环境执行：

1. 拉取所有镜像并核对固定 digest。
2. 在宿主机预拉取 `qwen3-embedding:0.6b`，记录模型清单和磁盘占用。
3. 限制 Ollama 只监听受信地址，确认 Docker 私有网络可以访问。
4. `docker compose up -d --build` 并等待必需服务 healthy。
5. 检查 vector 扩展、知识表、强制 RLS、复合外键和低权限授权。
6. 经 LiteLLM 执行本地 Qwen 单条、批量和多语言 1024 维验收。
7. 注册两个租户并执行相同/相似资料的全链路隔离测试。
8. 上传 TXT、文本 PDF、DOCX 并等待索引 ready。
9. 验证 child 召回、parent 上下文、reranker、引用页码和无证据拒答。
10. 删除被引用文件，确认立即失效、引用片段清理和历史 UI 降级。
11. 分别中断 embedding、reranker 和生成模型，验证预期降级。
12. 验证数据库和数据卷在容器重建后持久化。
13. 运行 `backend/scripts/non_ai_smoke.ps1` 和 `backend/scripts/ai_acceptance.ps1`。
14. 执行固定评测集并记录 Recall@8、MRR/nDCG、citation precision、无答案准确率和 P95。

只有所有 P0 阻断解除、复验通过、质量门槛达标后，才可将发布结论改为“允许发布”。

## 6. 非 MVP 与按阈值启用

以下内容暂不作为当前发布阻断：

- 扫描 PDF OCR、手写识别和图片语义检索。
- XLSX、PPTX、音频和视频。
- 外部网页抓取、云盘同步、浏览器插件和团队共享。
- 用户画像、模型训练或微调。
- Apache Tika；仅在真实样本证明 Poppler/标准库不达标时重新评估。
- HNSW；仅在精确向量扫描达到数据量或延迟阈值后，以独立迁移引入。
- 多集合关联；当前一个知识文件最多属于一个集合。
