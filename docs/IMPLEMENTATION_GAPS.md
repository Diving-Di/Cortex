# Cortex 未实现与待验证事项

> 状态：未实现、部分实现和待验证事项的唯一清单
>
> 更新日期：2026-07-29

本文合并原 `IMPLEMENTATION_GAPS.md`、OpenKnowledge 借鉴计划和小红书研究实现计划中
尚未完成的内容。已实现功能、历史实施记录和已经通过的验收结果不再保留；当前设计与
接口基线见 [软件设计说明书](SDD.md)、[API 文档](api.md) 和
[研究页面架构](page/RESEARCH_PAGE_ARCHITECTURE.md)。

状态定义：

- **未实现**：仓库中没有对应能力，或现有实现不能完成声明行为。
- **部分实现**：主链路存在，但分层、安全、恢复、测试或用户操作仍不完整。
- **待验证**：已有代码或配置，但缺少可复现的真实环境、并发、隔离、性能或生产证据。
- **非当前范围**：明确不进入当前产品范围，不作为发布阻断。

## 1. AI 与知识工作流

### 1.1 领域分层（部分实现）

- 增加统一的知识领域 DTO。
- 将 `Retriever`、索引编排和 Knowledge Chat Workflow 从 handler/store 细节中分离。
- handler 只处理 HTTP/SSE 契约，不直接创建模型客户端、拼接 Prompt 或编排 SQL。

### 1.3 Knowledge Chat 与成长助手（部分实现）

- 如集合需要成为可引用实体而不只是检索范围，增加集合级来源 DTO。
- 为文档提示注入、无证据、范围越权、来源失效和客户端断线补充后端测试。
- 补充 SSE 事件、停止、断线、无证据、引用失效、窄屏和可访问性前端测试。

## 2. 知识文档、索引与检索

### 2.1 解析和切块（部分实现）

- 已增加并自动解析中文、英文和中英混合 TXT/PDF/DOCX 固定测试样本。
- 覆盖损坏、加密、扫描、复杂多栏 PDF 和复杂表格，并验证多栏阅读顺序。
- 用自动化测试证明 PDF 页数、字符数、对象数量、解析时间和资源上限有效。
- 确认所有解析失败均返回稳定错误码，且日志不含正文、原路径或文件名。
- 扩充文档树、结构边界、表格和部分批次故障测试。

### 2.2 模型客户端（待验证）

- 经 LiteLLM 验证本地 `qwen3-embedding:0.6b` 的单条、16 条批量、中文、英文和混合输入，
  并确认返回数量、顺序及 1024 维。
- 覆盖超时、不可达、维度异常和部分批次失败。
- 用固定评测集记录 Qwen3 reranker 对 nDCG/MRR 的实际收益。
- embedding 内容缓存继续保持关闭；若以后启用，只允许同租户按
  `content_hash + embedding_model` 复用，并须证明不存在跨租户缓存。

### 2.3 Worker、删除与恢复（部分实现）

- 增加多 worker、多 backend、租约过期、幂等和故障重试测试。
- 覆盖删除、重传和索引并发，确保旧任务不能重新激活失效文档。
- 验证旧索引代次清理和模型升级回填不会混用向量空间。
- 保证知识文件 DELETE 幂等，并增加并发删除、详情跳转和下载回归测试。
- 明确原文件彻底删除及本地模型日志的保留承诺。

### 2.4 检索隔离与前端（部分实现）

- 增加相同文本、相似文本、相同文件名和相同摘要的自动化双租户隔离测试。
- 覆盖 collection/document ID 伪造、缺失 RLS 上下文和低权限角色。
- 固化 FTS 降级、reranker 降级、统一 token 预算和旧代次排除的端到端断言。
- 为知识库页面补充失败、无权限、索引中、响应式和可访问性测试。

## 3. 小红书研究

### 3.1 后端测试（部分实现）

- 补充任务状态机、取消、重试、租约续期/过期恢复和多 worker 并发 claim 测试。
- 补充来源去重、任务创建幂等、保存知识库事务与幂等、草稿结构校验和版本冲突测试。
- 补充图片 MIME/签名/尺寸、重定向 SSRF、目录穿越和敏感错误脱敏测试。
- 使用脱敏固定 fixture 或 mock server 覆盖页面结构变化、限流、部分来源失败和采集恢复；
  常规测试不得依赖真实账号或实时页面。
  已增加搜索卡片、详情弹层和安全验证三类脱敏页面状态 fixture，仍需继续补充平台真实
  页面发生变化时的脱敏 DOM 样本。
- 补充 AI 不可用、OCR 不可用、采集器不可用、进程重启和数据库重启的降级/恢复测试。
- 补充双租户任务、来源、草稿、资产和授权资源隔离测试；客户端伪造 `tenant_id` 必须
  无效，跨租户访问统一为 404，软删除租户普通请求为 403。
- 为迁移 `000003_xhs_research` 和 `000005_xhs_authorization` 增加真实数据库 up/down、
  回滚重放和重复执行测试。

### 3.2 前端测试与交互（部分实现）

- 研究页面已覆盖空状态、授权门禁、关键词任务、未知状态和加载失败；仍需覆盖链接任务、
  表单边界、进度轮询、页面不可见时暂停、筛选、搜索、排序和分页。
- 覆盖详情中的原文/OCR/草稿分区、编辑冲突、单条/批量保存、忽略、取消、重试和重新采集。
- 覆盖扫码授权的创建、轮询、二维码 Blob、验证、取消、撤销、过期和重新授权。
- 覆盖 401、403、404、409、AI/OCR/采集器不可用、部分失败、浅色/深色主题、窄屏、
  键盘操作、标签/替代文本和焦点恢复。

### 3.3 OCR、采集器和授权（待验证）

- 已参考 `xhs_research_and_classify` 增加 Go/Chromedp 动态搜索与详情采集器：授权任务
  优先使用浏览器等待、有限滚动、去重和详情 DOM 解析；受控 HTTP Collector 保留为公开
  URL 降级路径。仍需持续维护真实页面选择器 fixture。
- 已统一识别 `ready`、`login_required`、`verification_required`、`rate_limited`、
  `not_found` 和 `layout_changed`，并用于授权验证、扫码 worker 和动态采集。
- 已在详情轮播容器内过滤头像、装饰图、小缩略图和重复 URL，并持久化
  `published_at`、点赞、收藏和评论数量；仍需真实页面多版式验收，不采集评论正文。
- 搜索已增加有限滚动、无增长停止、URL 去重，以及综合、最新、最多互动三个受控排序；
  普通请求使用稳定的 ±20% 有界抖动，限流使用 `available_at` 持久化指数退避。
- 已将确定性正文/OCR 清理、可选 AI Markdown 格式化和摘要分类拆分，持久化解析策略、
  内容完整度、OCR 贡献、格式化正文和格式化状态。LLM 缓存保持默认关闭，若以后启用
  必须按租户、模型、Prompt 版本和内容哈希隔离。
- 已通过真实搜索页和详情页验明确认平台只恢复 Cookie 时不下发内容，因此扫码完成时同时
  保存经过数量、单项大小和总大小限制的小红书 localStorage，并与 Cookie 一起按租户加密；
  禁止照搬参考项目的
  永久明文 Profile、共享 `storage_state.json`、同账号并发浏览器、Python Web 后端、
  直连模型供应商、本地明文 LLM 缓存和 Markdown 权威存储。
- 在受限内部 OCR 服务上完成真实图片验收，确认字符上限、失败隔离及服务不可用时的
  人工审核降级；OCR 服务不得持有 LiteLLM Key、数据库业务凭证或跨租户文件权限。
- 验证采集器的域名白名单、DNS/重定向 SSRF 防护、大小/数量/超时限制、平台退避和
  页面结构变化错误契约。
- 用两个租户完成真实扫码授权、关键词采集、公开链接匿名采集、授权撤销和错误密钥验收。
- 验证 Chromium 临时 profile/二维码按期清理，不进入静态目录、导出或备份；API 和日志
  不得包含 Cookie、密文、nonce、二维码路径或页面源码。
- 制定并验证会话加密密钥轮换流程；当前实现要求用户在版本变化后重新授权。

### 3.4 备份、恢复和数据生命周期（部分实现）

- 完整备份已经包含研究来源、草稿、资产和知识文档，空租户恢复会重映射 ID；登录态、
  Cookie、API Key、Token、Provider、usage 和敏感审计均被固定白名单排除。
- 已有备份恢复脚本验证笔记、附件、空租户和 ID 重映射；仍需增加包含真实研究资产、
  知识文件重新索引和来源软删除的端到端 fixture。
- 明确第三方原图、OCR 文本、来源正文和授权临时文件的保留、擦除与审计策略。

### 3.5 可观测性（部分实现）

- 已增加任务创建/取消、知识库保存、授权启动及采集器/OCR/授权可用性指标；仍需补充
  各状态数量、端到端耗时、OCR/AI 成功率和耗时、限流、授权过期及租约恢复指标。
- 指标标签不得包含邮箱、姓名、关键词原文、来源正文或 URL。
- 验证结构化日志只记录追踪 ID、任务/来源 ID、状态和稳定错误码；URL 仅记录散列或
  脱敏标识，不记录页面 HTML、OCR 全文或 AI 完整输入输出。
- 通过功能配置接口或管理指标暴露可选采集器和 OCR 的可用状态，但不得影响
  `/healthz`；`/readyz` 仍只验证必需依赖。

## 4. 部署与生产证据

- 固定 Ollama 模型 digest，并在目标发布环境复核 reranker 镜像 digest 和只读模型目录。
- 验证研究采集器、OCR（如启用）和 backend 以非 root 用户运行且不暴露额外宿主机端口。
- 验证生产监控能够采集知识索引、检索和研究指标，且日志扫描不含 Key、Cookie、完整
  正文、文件名、原路径或第三方响应正文。
- 验证数据库、附件、知识文件和研究资产在容器重建后仍存在。
- 在全新 PostgreSQL 16 空库验证表、索引、外键、RLS、低权限授权和全部迁移；更新空库
  表数量及 RLS Policy 数量断言。
- 在目标环境运行 `non_ai_smoke.ps1`、`ai_acceptance.ps1`、
  `knowledge_acceptance.ps1`、`research_acceptance.ps1` 和需扫码授权的
  `research_live_acceptance.ps1`。真实脚本覆盖采集、内容诊断、整理和可选确认保存；
  跨租户隔离、授权异常和降级链路继续由自动化测试覆盖。
- 用固定数据集记录 Recall@8、MRR/nDCG、citation precision、无答案准确率、检索和
  端到端 P95，并覆盖冷启动与热启动。

## 5. 非当前范围

以下项目不作为当前实现缺口或发布阻断：

- OpenKnowledge 的通用 Agent 工具和网页搜索。
- 扫描 PDF OCR、手写识别和图片语义检索（不影响小红书研究图片的可选 OCR）。
- XLSX、PPTX、音频和视频知识解析。
- 外部网页通用抓取、云盘同步、浏览器插件和团队共享。
- 用户画像、模型训练或微调。
- Apache Tika；仅在真实样本证明现有解析链路不达标时重新评估。
- HNSW；仅在精确向量扫描达到数据量或延迟阈值后通过独立迁移引入。
- 多集合关联；当前一个知识文件最多属于一个集合。
