# 页面与使用流程

校对日期：2026-10-05。本文统一维护页面入口、交互、状态和测试；HTTP 契约见 [API](../api.md)，安全与持久化见 [系统设计](../SDD.md)。

## 路由与入口

| 路由 | 页面 | 入口与默认行为 |
| --- | --- | --- |
| `/login` | 登录/注册 | HttpOnly 会话；登录后进入工作台 |
| `/` | 工作台 | 快速记录、待处理、上周今天、最近笔记、周期报告提醒、活跃度、活动卡片 |
| `/notes` | 笔记本 | 始终跳转 `/notes/list`，旧浏览偏好不改变默认入口 |
| `/notes/list` | 笔记列表 | 类型、关键词、日期、标签筛选；新建与模板入口 |
| `/notes/templates` | 模板广场 | 公开模板与我的模板；作为记录辅助入口 |
| `/notes/:id` | 编辑器 | Markdown 编辑/预览、附件、标签、草稿恢复、冲突比较、历史与相关笔记 |
| `/knowledge` | 个人知识库 | 上传、索引、问答、历史、来源片段、反馈、保存回答 |
| `/reports` | 周期报告 | 来源、生成草稿、确认、已保存报告、差异、定时任务与运行记录 |
| `/ai-events` | 免费点数活动 | 从工作台活动卡片访问；不占一级导航，不自动弹窗 |
| `/settings` | 设置 | 主题和模板推荐偏好 |

`/recipes`、`/assistant` 兼容重定向到 `/knowledge`。已删除的小红书研究页面不恢复。

## 笔记与内容保护

列表默认显示全部类型。无关键词时使用 `/notes` 分页；关键词搜索使用 `/search`，结合类型、日期、标签返回最多 100 条，页面明确提示上限。
新建使用所选类型，全部类型下新建普通笔记；日期使用本地当天，周/月日期由服务端归一。
标签分配调用已有 PUT 接口，正文继续显式保存；标签修改是独立提交。

编辑器没有自动提交正文。sessionStorage 按账号和笔记 ID 保存未提交草稿；刷新当前标签页可恢复。
提交成功清理对应草稿，取消/离开保留草稿供恢复。浏览器存储失败显示提示，不宣称已保存。
路由离开和浏览器返回通过数据路由 blocker 提醒；页面关闭通过 beforeunload 提醒。
账号退出会先检查未保存状态，清空请求缓存；会话失效也清空请求缓存，防止另一账号读取旧查询结果。

收到 409 后保留本地内容，加载服务器最新正文、标题、日期并展示比较。用户手动编辑合并，
明确确认“使用最新版本”后才使用最新 `expected_updated_at` 再提交。再次冲突继续保留草稿。
差异界面以线性复杂度保留相同首尾行、高亮变化区间；不执行自动合并或逐词 diff。

历史列表展示时间、原因和正文预览；恢复要求确认，并提交显示版本的时间戳。
恢复只恢复历史正文；服务器当前标题、日期继续有效，界面同步重新加载。原服务器正文成为 before_restore revision。
没有 revision 标题、日期、报告来源快照，不能把正文恢复描述为完整文档状态恢复。
同标签笔记优先显示；没有标签时展示最近一周记录，不增加图数据库。

## 工作台与待处理

快速记录可以直接保存原文，也可以生成结构化整理稿。生成结果需有合法标题和正文，确认前比较原文与草稿。
原文生成后发生变化时禁止保存旧整理稿；重新整理失败保留上一份完整草稿。
记录与整理稿保存在当前标签页，保存服务器后清理。

待处理卡片聚合本地草稿、知识索引失败和定时报告失败，提供继续/查看原因/重试入口。
定时任务最多检查前 20 项的最新运行，全部任务仍从周期报告页查看；不是全量通知中心。
各查询有独立失败提示，部分服务异常不隐藏仍可用的草稿。
回顾卡片显示本地日期上周同期笔记。活动信息留在普通卡片，加载失败不阻断记录。
应用 AI Token 数为字符估算，界面标注估算，不作为账单。

## 周期报告

周一/月初决定草稿键。`/reports?type=weekly&date=YYYY-MM-DD` 可恢复指定周期草稿。
切换周期/类型清空当前来源、生成状态和未完成片段，并按新周期恢复草稿；epoch 防止旧异步结果覆盖新状态。
来源加载和生成期间禁止重复操作；生成时禁止切换周期，可主动停止。
报告 SSE 的 sources 事件携带本次实际来源，草稿确认使用这些来源 ID，服务端仍做租户与周期校验。

生成中显示独立尝试；只有完整结束且携带来源的结果才成为可保存草稿。
失败/取消不覆盖上次完整结果，也不从头自动重试。草稿可手动编辑并与已保存报告比较。
当前标签页保留最多五次成功生成草稿，支持只读比较及恢复为待确认草稿；失败尝试不覆盖成功历史，保存服务器后清理浏览器历史。
周期已有报告时明确确认覆盖；服务端保留 report_before_overwrite revision。
已保存报告链接到笔记编辑器查看/恢复正文历史；本轮未增加服务端生成尝试存档表。

定时任务仍使用持久化 running/success/failed、有限租约、IANA 时区和 queued 重试。
创建、启停、立即重试及运行记录沿用现有接口；创建失败与重试失败应提供用户提示。

## 知识库

MD/ZIP、PDF、DOC/DOCX、PNG/JPG/WebP 依既有安全解析/OCR 流程摄取，每租户 3 GiB。
ZIP 仍只解析 Markdown、PNG、JPG，不新增 Excel/PPT 摄取或分片上传。
文档列表轮询阶段和进度；失败或旧版本重建失败可重试，旧活动版本继续可用。

问答回答、来源、澄清和历史为主要内容。检索技术阶段默认折叠，用户可主动展开。
来源标题打开有限片段、章节与索引版本；笔记来源可打开原笔记。新流片段最多 1200 字符，
历史引用使用服务端已保存的最多 500 字符快照；PDF 页码依解析 Markdown 分节，尚无坐标高亮。
历史回答来源按当前有效版本复核，失效来源不返回。没有当前证据时仍拒答。

完成回答可确认保存为普通笔记：客户端只提交 message ID，服务器读取完成回答、复核当前租户来源、
配额及笔记有效性，在同一 RLS 事务保存正文与来源快照。重复请求返回已存在笔记。
失败回答不可保存；来源删除、禁用或索引版本变化返回错误，跨账号访问返回 404。
不自动开启保存笔记参与知识库，避免回答被自动循环摄取。

## 模板和活动

模板保留私有 CRUD、作者自主发布/撤回、公开快照、榜单、搜索、收藏、点赞和使用统计。
使用模板继续通过幂等键创建笔记；个人化推荐由设置开关控制。暂不扩展评论、关注、私信、团队或计费。
公开模板内容由作者主动公开，个人笔记和知识库不会自动公开。模板缓存、Outbox、fencing 等实现见专项基础设施和 API。

活动按服务端时区、开放时段、名额、奖励和连续记录资格展示；领取使用既有幂等、Redis 原子预扣与数据库最终事实。
领取成功意味着获得免费 AI 点数，不代表已生成深度月报。活动历史及点数明细仍在活动页。

## 引导与验证

笔记、知识上传、报告提供首次访问的可跳过分步说明；可从“使用引导”重新打开。
引导偏好按账号保存在 localStorage，仅保存已看标记。正文草稿与密钥不进入该偏好存储。

Vitest 覆盖默认路由、过滤、草稿隔离/过期、存储失败、保存响应等待、冲突合并、历史恢复、
报告来源绑定、异步失效、失败保留、引用查看、问答保存、索引重试、活动非打断和导航保护。
Go 集成测试覆盖新接口的 RLS、跨租户、来源失效、配额、幂等并发与恢复版本冲突。
浏览器 E2E、完整 Compose 和真实 AI 验收范围由当期 [验收记录](../operations/README.md) 单独说明。
